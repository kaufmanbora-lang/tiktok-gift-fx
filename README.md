# 🎁 TikTok Gift FX

Эффекты **поверх любой игры** за подарки в TikTok LIVE. Вводишь свой юзернейм — программа ловит подарки
и сама показывает эффект, а потом сама закрывается.

| Подарок | Эффект |
|---|---|
| 🐹 Хомяк | 😱 Скример на весь экран — резкий и громкий |
| 🔫 Деньгопушка | 🐱 Три танцующих котика «вам повезло» на весь экран, 15 секунд |
| 🥊 Боксёрские перчатки | 💥 Флешка как в CS: яркость монитора на максимум, белый экран 20 секунд, писк в ушах; потом яркость возвращается |

Каждый подарок — отдельный эффект, по очереди. Есть тестовые кнопки, чтобы проверить всё без эфира.

## ⬇ Скачать

**[Последняя версия → Releases](https://github.com/kaufmanbora-lang/tiktok-gift-fx/releases/latest)** — файл `TikTok-Gift-FX-Setup-….exe`.

1. Запусти установщик. Если Windows покажет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**
   (программа не подписана платным сертификатом).
2. Программа поставится и откроется сама, ярлык появится на рабочем столе.
3. Впиши свой юзернейм TikTok → **Подключиться**.

Работает на любом компьютере с Windows 10/11 (64-бит), ничего дополнительно ставить не нужно.
**Обновляется сама**: новые версии скачиваются в фоне и ставятся, когда ты не в эфире.

## Советы

- Если в игре эффект не видно — поставь в игре режим «Оконный без рамки» / Borderless.
- Чтобы зрители видели эффекты — в OBS / TikTok LIVE Studio используй «Захват экрана».
- Яркость внешнего монитора меняется через DDC/CI — если не меняется, включи DDC/CI в меню монитора.
- Стоп всех эффектов: **Ctrl+Shift+End**.
